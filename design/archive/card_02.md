## 1. 主体内部核心系统

- **知觉 / 世界模型**：从感觉帧推断对象、事件、来源和 affordance；维护部分可观察信念、unknown 和行动后的多未来预测。
- **身体 / 自我模型**：维护身体和接口边界、能力限制、当前目标、来源先验、记忆/知觉边界、连续状态和自我预测误差。
- **功能性感受**：valence, arousal, urgency, controllability, uncertainty, novelty, social_relevance, tendencies, persistence。
- **记忆系统**：working、episodic、semantic、procedural、affective value、prospective、autobiographical、metamemory；recorder 不是主体记忆。
- **递归工作空间**：有限容量竞争→WorkspaceFrame→广播→读取回执→模块更新→再次竞争；广播不改变认识层级。
- **动机 / 目标**：viability、模型失配、情感、机会/请求、承诺、规范、好奇 → GoalCandidate → 主体采纳 → OwnedGoal。
- **控制器 / 规划**：Reflex、Habit、Model-based、Active perception、Language/social 并行提案，由元控制选择行动、观察、思考、求助或放弃。
- **元认知 / 学习**：监控可靠性、冲突、失控、预测失败和能力边界；快速经历、有限适应、慢速巩固和保护集共同约束改变。

## 2. 情感、工作空间和行动的因果纪律

- **情感不是 reward**：FunctionalExperientialState 是持续动力学的结构化投影，必须有积分、迟滞、衰减、饱和、恢复、重新评价和后果校准；不能直接发动全部行动。
- **广播不是全局访问证明**：内容按目标相关性、情感、新颖性、不确定性和信息价值竞争；广播需有模块读取和可测状态变化，才能支持因果访问。
- **意图不等于执行**：控制器提案→行动意图→授权→提交→独立执行事实→主体收到回执/结果→归属→目标结算；主体不读取隐藏执行真值。

## 3. 并行多时间尺度运行

| 循环 | 活动 | 循环 | 活动 |
|---|---|---|---|
| 快速 | 信号接收、感觉形成、动作控制、反射保护 | 知觉 | 感觉场、多模态融合、世界/身体估计、预测误差 |
| 认知 | 工作空间竞争、记忆检索、目标与计划更新 | 情感 | 内感受、评价、持续情感和有界调制 |
| 行动 / 学习 | 控制器竞争、动作预测、执行、回执、归属、模型/技能更新 | 巩固 | 经历重放、语义抽象、遗忘控制、自我一致性检查 |

- **内部认知闭环**：接收→感觉↔感觉预测↔知觉↔模型/感受/注意/记忆↔工作空间目标/规划→行动。负责产生和维持候选主体的智能组织。
- **外部证据闭环**：世界事实→收到信号→主体状态变化→行动→世界后果→收到结果→归属与长期变化。负责验证内部机制是否真实工作，而非自我叙述。

## 4. 门后实现路线

| 阶段 | 形成的能力 | 核心通过条件 |
|---|---|---|
| C0 | 数字身体、接收、Sensorium、确定性认知底座 | 接收/感觉/知觉边界、来源、校准、时序和重放可审计 |
| C1 | 多模态知觉、世界/身体/自我模型 | 预测和不确定性校准；感觉、信念、自我/外部来源可区分 |
| C2 | 持续感受、感觉增益、记忆、递归工作空间 | 有界增益和至少三类下游因果调制通过消融 |
| C3 | 驱力、候选/拥有目标、承诺、控制器 | 请求不直写目标；情感和驱力不直达执行 |
| C4 | 行动预测、归属、元控制、语言/社会认知 | 新情景迁移、理由敏感选择、来源区分和语言权限成立 |
| C5 | 感觉适配、持续学习、巩固、纠偏、防遗忘 | held-out 改善且保护集不退化 |
| E1 | 集成证据：模块 lesion、edge ablation、角色交换、录制回放、M0-M2 回归、六类核心决策全路径 | 选择性损失、原始记录可复算、无各类旁路、unresolved_paths[] 为空且分母闭合 |
| H1 | 平台硬化：长时运行、故障注入、checkpoint 稳定/迁移、profiling 后并行化、恢复演练与可复现发布 | 冻结 manifest 可重建；独立人员可运行/恢复/复算；性能优化不破坏确定性和证据兼容 |
| P1 | 物理具身：PhysIO Bridge、设备认证、非学习有界 PhysIOControlGraph、版本化 BodyGraph、passive→active、L0-L5 控制 | 仅在 E1+H1、PhysIO 安全评审、最高物理权限授权、外部独立急停后启用；四类独立记录任一失效 fail closed |

**不可颠倒**：F0 → M0 → M1 → M2 → R0 → ALLOW_NEXT_STAGE → C0 → C1 → C2 → C3 → C4 → C5 → E1 → H1 → independent physical authorization → P1

## 5. 防错原则

模块数量≠智能 | LLM 自述≠自我模型 | 单 reward≠情感/动机/价值 | 共享数据库≠全局整合 | 日志≠主体记忆 | 脑区命名≠因果功能 | 行为相似≠内部机制证据 | orchestrator 不得替主体形成目标/决定 | 功能性感受≠意识证明。
