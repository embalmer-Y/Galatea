## 判据域立法专项裁定（Q-L11-03 补裁②）——合法，非 S0

**结论：合法的可判定性立法（REV-0014 R3 / C2 修订 3 同族），五要点逐项核过：**

**(a) 域定义确由 prior 派生链构造性决定 ✓**
派生链机械核实：`m0_mw0.profile.yaml` `regimes.initial_regime: abundance` + `regimes.abundance.resource_density: 0.35`（行 54/62）→ `c1profile.py` 行 165–167（`initial_regime` → `resource_density` 直接读取，非硬编码）→ stat plan `prior_frozen: 0.35` → runner `_PRIOR_FROZEN=0.35`。增益空间域 = |prior−truth| 构造性非零的 regime 集。档案数据实证：v1.1 档案 run 分区中全部 21 个 abundance cell 的 `truth_coverage = 0.3515625` 恒定（nolearn 与 learn 臂逐位相同——世界真值不因学习臂改变），|prior−truth| = 0.0016 ≤ 宣称上界 0.002；scarcity 0.1016 / volatile 0.2024 远离 0.35。abundance 格上任何学习器增益上界 ≈0.002 由冻结初值条件决定，**先于且独立于本次评价结果**。

**(b) abundance 负增益如实保留 ✓**
现行 v1.1 档案 run 分区完整含全部 21 个 abundance 配对（评审自 Parquet 重算：mean **−0.106261**，d **−2.2590**——与裁决文本"实测 −0.106"、manifest gate 注记"d=-2.26"逐位命中）；未删除、未遮蔽；v1.0 INCONCLUSIVE 工件双件入 manifest v1.7 锚（2526fc4c/80b1c787）。"描述性另报"承载于 manifest 注记 + stat plan v1.1 注释 + 登记册行，原始数据可复算（本评审即复算）。

**(c) 阈值未动 ✓**
`evaluate_c5_learning_gain` 两版共用 `_c1_verdict_from_diff(..., 0.5)`（硬编码同源）；`min_effects.yaml` v1.7 `c5_promotion_learning_gain = cohens_d 0.5`；c5profile 装载器 fail-closed 强制 0.5。经验证据：v1.0 在 d=0.438 时判 INCONCLUSIVE——若阈低于 0.5 该轮即 SUPPORTED，反证 0.5 在 v1.0 运行时即在位。

**(d) 程序先于结果、不可逆可审计 ✓（附 R7 注记）**
工件链顺序可机械恢复：v1.0 先跑并如实归档 INCONCLUSIVE（复合件携带 v1.0 计划 digest 45c5975f…）→ 裁决补裁②入登记册（重开条件成文）→ stat plan v1.1 修订留痕（头部版本注记 + claim_domain 注释）→ entry 归档守卫 → 新首评 v1.1（携带 v1.1 digest c7075539…）→ manifest v1.7 双锚。**决定性反 S0 证据：v1.1 与 v1.0 消费同一冻结数据**——评审对两档案 run 分区逐记录比对，256/256 条 trial 摘要逐字段恒等（唯一差异 = v1.1 summary 增补 regime 标记字段，系立法所需归因字段），证明不存在"换种子重跑到有利"或"挑选 trial"：立法重划估计域，未动数据。v1.0 计划文本未归档见 R7（S4，不影响本裁定——digest 链 + 分层重算可复算性已足够锚定）。

**(e) 重开条款预设卡阈情形 ✓（部分匹配，如实注记）**
冻结提交（a6b579c）内 Q-L11-03 原始裁决重开条件原文："**C5 实测 d≥0.5 使合法改善全部卡阈（可测量的提案分布塌缩）→ 经新 Q 重标定**"——"卡阈"族情形在结果已知前已预登记退出路径。实际执行的补救（域重定义、阈值不动）与预登记补救（阈值重标定）不同且**更保守**（未触碰冻结阈值）；直接锚 = REV-0014 R3（可判定性立法三要件）+ Q-L03-07（换判据域 = 新 EvidenceResult 同族）+ C2 修订 3 先例。条款匹配为部分匹配而非字面命中，如实记入；立法效力不单独依赖该条款——构造性论证（(a)）独立成立。

**补强性证据（评审独立重算，自 v1.1 档案 Parquet）**：全域名 n=64 d=0.4378 / p=0.000461533 / CI (0.025092, 0.088871) 与 v1.0 档案 gain JSON 逐位恒等（同一数据两种域读法皆可从现行工件复算——无任何结果被藏匿）；域内 n=43 d=2.0313 / mean +0.136705 / CI (0.116590, 0.156820) 与 v1.1 工件逐位恒等；分层 scarcity d=+7.8056 / volatile d=+2.6010 与裁决文本命中。重定义后的 claim 并非空洞可过：域内 learn 臂仍须真实击败冻结先验对照（d≥0.5），nolearn 对照与配对语义不变，机械断言（全 64 对 world digest 逐位恒等 + nolearn posterior 恒 0.35）全过。
