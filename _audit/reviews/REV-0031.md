## 二、Findings（分级 + 闭环要求）

### R1（S2）claim1 冻结判据存在退化策略等价——MPC 臂实为常量 rest 策略，SUPPORT 不能承载"模型内搜索因果贡献"假设语义

**证据（评审侧机械实证，非推测）**：
1. probe_report.json：`mpc` 臂 8/8 种子 mean_energy **全部恰 = 1.0**（= energy_max 上界；MW0 初值 = energy_max，mw0.py:53；`_gain_energy` 上界截断 mw0.py:216）——实测 advantage 0.0647 **恰 = 1.0 − mean(script)**，即 MPC 拿满了可达优势的 100%，测量处于判据天花板。
2. 评审侧诊断（训练后 plan_trace，world 0/3/7）：首动作 64/64 = **rest**；计划 RRFF 63/64；mean = min = 1.0；**in_band = 0.0**（runner 自带 [0.3, 0.95] 健康带判定下 MPC 全程带外过饱和）。
3. 构造性等价：常量 rest 策略（恒选 rest）自同一初值出发与 MPC 实现轨迹逐位同值（rest +0.10 恒被截断于 1.0）——**常量策略可得与 EFE-MPC 完全相同的 claim1 分数**。
4. 后果：claim1 假设文本"若无优势 → 模型内搜索无因果贡献"的逆命题不成立——SUPPORT 时**不能**推立"模型内搜索有因果贡献"（一个无模型的常量策略同分）。EFE set-point = 0.7 的立法语义（稳态偏好）与"钉死上界"的胜出行为存在方向张力（真追踪 set-point 的策略 mean ≈ 0.7 < script ≈ 0.935，将在冻结 estimand 上**输**给脚本）。
5. 判据面缺陷但非失实：探针如实记录了它测到的（artifact 透明、mpc_scores [1.0×8] 在档）；INC-08 可击败性字面满足（script 基线 8/8 可击败、有拒收臂、有遗忘对照）——但 claim1 的基线族（script + 描述性持续/随机）**不含能暴露退化等价的常量策略对照**。

**闭环要求（冻结提交内，运行前修订路径）**：stat plan v1.0 → v1.1 运行前修订（判据零 claim 运行，修订合法）：① qualifiers 增 ceiling 披露（MPC 臂饱和于 energy_max、优势测量顶格、set-point 张力）；② 增常量 rest 去功能基线为描述性同场测量（Q-L13-19② / REV-0030 R4 先例——claim1 SUPPORT 的诚实解释需 MPC ≥ 常量 rest 或显式登记等价）；③ claim runner 消费 in_band/min_energy 副面留痕（run_episode 已返回、探针未消费）。ADR-G-0035 §2/§3 同步注记。若作者判断需改任务形（如非饱和初值），亦为合法运行前修订——但须先证新基线可击败（INC-08）。

### R2（S3）载体三门"新任务改善"参照为跨数据集比较——A 案例拒收依赖非同尺 yardstick；同尺参照下拒收面消失

**证据**：`dual_gate` 的 improve 判据 = `heldout_mse(model_c, phase2_holdout) ≤ post_a`，而 `post_a = heldout_mse(model_a, xs1[half1:])` 是**仅微调臂在旧任务（phase1）上的 MSE**（forget_a 的基数）。即"新任务 MSE ≤ 另一数据集上的 MSE"——两个 MSE 无自然序。ADR §2 文本"新任务 held-out ≤ 仅微调臂"的自然读法（同数据集：候选新任务 MSE ≤ 仅微调臂新任务 MSE）下，案例 A 自比较恒真等式（0.0016122 ≤ 0.0016122）→ **A 被 admit → 探针门判别 FAIL**。换言之"A 拒"这一判别面依赖跨数据集参照的选择。Q-L11-09② 立法语义"新任务 held-out 改善"的规范参照（相对父模型 P1 的新任务 MSE）在探针中**未测量**。另：报告字段名 `post_a_p2` 实载旧任务 MSE，命名误导。
**闭环要求（冻结提交内）**：运行前修订明确参照语义（建议 = 候选新任务 MSE 相对父模型 P1 新任务 MSE 的改善，参照值入档）+ ADR §2 载体三文本对齐 + 工件字段名勘误；20 构造案例（claim3）按修订后语义构造。

### R3（S3）ADR §2 候选集名第 7/8 项与冻结代码不符——"全量成文"复算规格存在名实分离

**证据**：ADR §2 "PLANS 冻结集：RRRR/RRRF/RRFF/RFFF/FFFF/MMMM/**RMRF/FRFR**" vs 代码 `PLANS[6]=(0,1,0,1)`=**MRMR**、`PLANS[7]=(2,0,2,0)`=**FMFM**。§2 是 REV-0013 R1 纪律下的唯一复算规格；按文本重实现者将构建不同候选集（复算必败）。代码与锚定 artifact 一致（真值源在代码），探针结论不受影响；profile mpc 注释"PLANS——ADR-G-0035 §2 原文"指向有缺陷文本。
**闭环要求（冻结提交内）**：ADR §2 勘误为 MRMR/FMFM（REV-0026 R5 行内勘误先例——原文不改、勘误注记为准，或冻结提交内直接更正成文并留痕）。

### R4（S3）EWC λ 立法链断裂——Q 行承诺"λ 冻结探针值"而探针无 EWC 组件

**证据**：Q-L11-09④"λ 冻结探针值"与 Q-G00-16"EWC λ……锚硬机制第九次探针实测"均承诺探针锚定；runs_p4gamma.py/p4gamma_probe.py **零 Fisher/EWC 代码**——不存在 λ 探针值。profile `ewc_lambda: 0.0`（默认禁用，注释诚实：重放为主保护 + 启用 = 运行前修订 + 新 Q 重锚）+ ADR §4 同式。**λ=0 本身是诚实立法非伪数值**（显式禁用语义 + 重开路径，重放保护的实证基础 = 探针 forget_b 反改善）——缺陷在引用链：profile/ADR 引 Q-L11-09④ 作为 λ=0 依据，而行文承诺的是另一个东西。
**闭环要求（冻结提交内）**：Q-L11-09 行内注记（行内补裁先例充分）：λ 冻结 = 0.0 默认禁用（重放为主，探针 forget_b < 0 为实证锚），启用路径 = 运行前修订 + 新 Q；Q-G00-16 行同步注记 EWC λ 例外。Fisher 对角近似的实操化留实现期（启用时）。

### R5（S4）claim2 判据形与 Q 行措辞差 + 探针单相位对实现的 qualifier 覆盖不对称
