## 决策

| 节 | 内容 | 溯源 |
|---|---|---|
| checkpoint | 周期性 = T6 边界 64 cycles + 事件触发（episode 边界/干预生效）；digest_refs_only（无全量复制）；parent DAG | Q-L00-05、L00 §3 |
| memory_min | **M2 最小连续性切片**（working 8 + episodic 128，强度初值 0.5、每 T6 ×0.9、检索 top-4/per-T4、来源类型强制、RECALLED 禁提升）——完整分层记忆 = C2 门（Q-L06-01/02/03），本伞式不预支 | Q-G00-11、L06 §1/§8 |
| sc5 | 四臂对照（full_continuity/freeze_restore/reset/pseudo_update）；reset = 清空 working/episodic 保留谱系（L06 §4.5 原文）；伪更新检测 = lineage_break；延续主张 gap=0 / 分支主张 gap 允许 | Q-L04-06、L01 §4.6 |
| sc6 | sealed 网格引用 F0 冻结的 sealed_split_policy；held-out 判据 = m2_continuity_carryover（d≥0.5） | Q-L13-02、min_effects v1.2 |

**M2 退出判据承载（HLD §10.2 M2 行四项）**：held-out 达冻结最小效应（sc6 + min_effects#m2_continuity_carryover）｜随机分支 intent-to-treat（intent_to_treat 节 + L00 §9 M2 行 RNG 分支隔离验证）｜保护指标不退化（protection_suite 只增不减 + L13 §4.5 门退出增补义务）｜有害更新可再次纠正（Q-L11-05 三步闭环 + L11 §4.5）。
