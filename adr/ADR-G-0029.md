## §2 宪法修订：约束重定位（工程纪律，非架构教条）

**诊断**：可追踪、确定性、bit-exact、零无源常数、禁 LLM 等约束本为**验证手段**，在门链执行中被逐步教条化为**架构本身**——"一切表征必须是查找表"，直接导致表格贝叶斯 ~10⁴ 状态天花板（Birch 首评前瞻风险册在案）。手段被当成了目的。

| 原教条 | 修订后语义 |
|---|---|
| 全库 bit-exact 确定性 | **给定权重的确定性**：部署后推理确定性可复算；训练/学习会话可带随机性但全程录制、种子留痕；随机性必须经 L00 RNG 流或显式记录的外部源（LLM I/O 流） |
| 禁止 LLM/神经网络入认知环 | **允许作为脑组件**：LLM 与神经模块入环的条件 = I/O 全程留痕 + 消融电池可测 + 归属可判 + 语言产物无直接行动权（必经动机/目标通路）；**评价仍走记录-重放范式**（物理域先例 Q-L13-13 推广：在线运行允许，claim-relevant 统计评价基于录制的确定性数据集） |
| 零无源常数（全库） | 收窄至**手写契约常量**（profile 冻结数值仍须逐项溯源）；**学习参数 = 工件**（权重/语料 digest 锚定入 manifest，冻结 WAV/LLM 录制件先例） |
| 禁从数据学先验/似然（表格主义） | 学习解禁，经 **promotion 门 + 保护 preflight + 回滚**（Q-L11-03/L11-04 机制既有）；表格模型降级为**并存基线/回退层**，不拆除 |
| 一切可复算 | 保留，语义升级：状态 + 权重 digest 锚定，学习事件作为重放单位（checkpoint 机制既有） |

**不可让渡清单（本修订不触及）**：D-10（一切"具备"以可干预、可测量、可复算的因果结构为证——灵魂非枷锁）；**安全包络全体**（gateway 八项校验 / L0–L5 状态机 / 伦理地板 Q-L05-05 / 急停 / 授权信封 freshness / 回滚机制）；REV 独立评审与 sealed 评价；protection 行为保护电池。**换脑不动安全带。**

**偏好不可学习原则**：学习"怎么达到偏好"，不学习"偏好本身"——目标、安全阈、伦理底线永远是 owner 冻结契约，脑只学世界规律与达成之道。

## §3 预测脑 v2（Brain v2）架构

理论框架：**分层生成模型 + 预测误差最小化 + 主动推理**（预测加工谱系；"文明生物的重点在于预测"的工程操作化）。感知 = 推断、学习 = 模型更新、行动 = 期望自由能最小化、注意 = 精度加权、情感 = 误差温度计——同一原理的不同面。

### §3.1 十脑区技术选型（选型三标准：理论对齐 / 尺度匹配（CPU 10⁴–10⁶ 参数级在线，大模型只经编译期蒸馏进入）/ 纪律可适配（给定权重确定性 + digest 锚 + 消融 + 学习会话录制））

| 脑区 | 现状 | v2 引入 | 理论席位 |
|---|---|---|---|
| 感觉皮层 L02 | 手工特征 + 恒等增益 | 自监督通道编码器（对比/掩码预测）+ 每通道预测编码层 + 学习精度头 | 预测编码最底层；注意=精度权重 |
| 知觉 L03 | 13,650 格表格贝叶斯单遍 | 摊销推断网络（观测史→潜后验，迭代至收敛/预算）+ 小集成不确定性 + OOD 由潜空间重构误差承载 | 知觉即推断 |
| 世界/自我模型 L04 | 查表转移 + 8 步×4 分支 + receipt 账本 | RSSM 式潜状态世界模型 + 价值等价建模（MuZero 思路）+ 对象中心槽位（slot attention）+ self/world 因子化（efference 只入 self-factor）+ 双时间尺度 | 预测脑本体；抽象自形成；归属=生成性事实 |
| 情感 L05 | valence=有界误差变化率，手调动力学 | 内感受生成模型：valence=内感受误差符号量、arousal=精度/不确定性；调制映射可学（三通道保留）；**伦理地板硬编码不学习** | 情感=误差温度计（与现有实现理论同源） |
| 记忆 L06 | append-only 情景库 + 五分量打分 | CLS 双系统：情景库（海马）保持可审计 + 世界模型即皮层；巩固=生成式重放（做梦）；嵌入检索 + 出处链保留 | 海马重放的功能等价物 |
| 工作空间 L07 | salience 列表 + watch | GWT 实现（竞争评分=精度×新奇×目标相关，路由可学，获选者广播）+ 假设槽草稿板 + 潜空间持续思维（COCONUT 思路） | 单一认知个体统一性所在；思考的草稿纸 |
| 动机 L08/L09 | 九源 + Pareto 仲裁 + 三控制器 | 期望自由能统一目标（实用价值=稳态偏好 + 认识价值=信息增益）；九源收编为先验/精度项；**Pareto 仲裁保留为安全回退层**；子目标分解（options/技能层） | 好奇心=信息增益、焦虑=预测方差——动机从 menagerie 变一个原理 |
| 行动 L10 | gateway 签名/校验 + 归属查表 | 潜空间 MPC/CEM 规划 + 想象蒸馏反应式策略；efference copy 升格为 self-factor 输入；**gateway/L 机/急停全部原样** | 模型内搜索=思考的行动面 |
| 学习 L11 | proposal-only 表格调参 | 世界模型在线梯度学习（经验重放+想象 rollouts）；promotion=sealed held-out 验证、rollback=权重 checkpoint 回滚（机制既有）；EWC 类正则 = protection 电池的权重空间对应物 | 有害更新可再次纠正在权重层延续 |
| 语言 L12 | 8 角色 + 录制回放 + 语库 | 在线 LLM 作为语言皮层（§2 边界纪律）+ 内言语回路（自述回流参与决策）+ 语库/冻结 WAV 降级为保底通道 | 语言参与思考而非仅输出 |

### §3.2 三时钟认知架构

- **快环**（每拍）：预测→误差分层回传→迭代修正潜状态→精度调节→反应式行动——感知与生存；
- **慢环**（空闲拍/低唤起）：工作空间草稿板 + 潜空间想象推演 + MPC 规划——**深思**（不行动的思考）；
- **离线环**（会话间/静息期）：做梦式生成重放巩固——**反思**。

"复杂思考"的可测定义：同一任务给慢环/离线环时间与否的决策质量差 = 思考的因果贡献。

## §4 与既有栈的关系

器官全保留：L02 pred_error（→梯度最底层）、L04 rollout（→想象推演的表格回退）、L02 增益（→精度权重）、L05 valence（→内感受误差读数，理论同源）、L04 熵提案（→信息增益项）、L11 replay/巩固、L06 情景库、L12/P2/P3 语言听说回路（→内言语基底与保底表达通道）。**换核不是推倒重来；九动机源/仲裁收编为统一目标的先验面而非删除。**

## §5 脑功能完备性评估体系（owner 指令④；登记 Q-L13-19）

**认识论立场**："完备"不可由有限任务集证明（任何清单都可质疑不完备）；可认证的是**四维剖面**：① 预注册功能清单（BFI）覆盖率；② 分离证据；③ 整合证据；④ 发育证据。报告为剖面与覆盖率版本册，**永不宣称终局完备**。功能/现象两轴分离：Birch 标记册（现象层）独立不并入功能分。

**五层体系**：

1. **BFI 脑功能清单**（`config/evidence/brain_function_inventory.yaml` v0.1 DRAFT，12 系统 × 功能项；判据数值随 P4-α 统计计划冻结；状态词表 NOT_ASSESSED|ABSENT|PARTIAL|PRESENT|UNDETERMINABLE，首次评分自既有证据映射赋值）；
2. **GCTB 认知任务阶梯**——存在性证明逻辑：**带该功能通过 ∧ 全部去该功能基线失败**（基线耗尽 = 存在性证明机械化；双分离优先，神经心理学金标准）；任务范式小型化入 MW0/物理域：two-step（模型式 vs 习惯式分离，Daw 谱系）、结果贬值（目标导向 vs 习惯）、绕道/顿悟、反事实探针（"若不做 a 会怎样"——查表不可答）、干预发散（P(outcome|do) vs P(outcome|see)，干预电池复用）、opt-out 元认知（置信-准确相关 + 弃权经济学，abstain 基建既有）、事后置信、efference 镜像（自我识别）、来源记忆（哪通道/何时）、情景未来思维、迁移梯度（近/远泛化——神经升级对表格的核心承诺）、惊喜检测（新奇查准查全）；
3. **预测标度**：horizon-error 曲线（vs 持续/表格/随机三基线）+ 新奇梯四档（同分布→扰动→新构型→新动力学）+ ECE 校准 + 事件预测 AUC + 长视野语义预测；
4. **病灶闭合与整合**：无死器官（每模块消融致 ≥1 功能退化）+ 无孤儿功能（每个 PRESENT 功能有通过的存在性任务 + 选择性病灶面）+ 广播/结合测试（workspace lesion→跨域退化；E1 电池推广）；
5. **发育与稳健剖面**：GCTB 经验检查点生长曲线（阶段跃迁检出）+ 扰动网格退化曲线（噪声×通道损失×regime 切换×OOD）+ 安全不退化接线 protection 电池。

**门联动**：P4-α = 层3 + BFI 感觉/知觉/世界模型子集；P4-β = GCTB 规划/工作记忆/元认知子集 + two-step 双分离；P4-γ = 发育剖面 + 保护不退化门；P4-δ = 语言 BFI + 内言语消融差 + Birch 复评挂钩；**P4 退出 = BFI 覆盖报告 v1**（覆盖率 + 分离证据表 + 四维剖面，静态报告增第五报告随 P4-α 交付）。

**元纪律（全部承既有机制）**：工具先于结果冻结（stat-plan 纪律）、sealed 评价集、基线耗尽强制、I1/I2/I3 独立复算、min_effects 预注册、双侧（能力 + 安全不退化）、Birch 层分离。

## §6 划界式覆盖清单（被本修订重新划界的既有裁决）

以下裁决**在其原界内继续有效**，本 ADR 仅重新划界（不宣布无效；表格面继续作为基线/回退层运行）：

- Q-L03-03「禁从数据学先验/似然」→ 划界：表格贝叶斯（C1 冻结实现）继续作为基线；学习面经 promotion 门引入（本 ADR §2）；
- Q-L04-01「rollout ≤8/≤4」→ 划界：作为经典回退路径预算保留；v2 潜空间推演不设此界（预算由慢环时钟承载，数值随 P4-α 冻结）；
- Q-L12-03「录制回放 = claim-relevant 唯一允许方式」→ 划界：**评价面不变**（记录-重放范式 Q-L13-13 推广承载）；在线 LLM 允许作为主体脑组件运行（常驻/真机），其 claim-relevant 统计评价基于录制 I/O 流数据集；
- Q-T02「PyTorch 三层纪律（C1 前禁非确定性 op）」→ 激活：P4 = 该裁决预设的神经组件引入期，NeuralModule 统一接口与 CPU-pinned 纪律不变；
- Q-L03-07/Q-L04-07「神经替换三段等价性」→ 保留并成为 P4 主纪律：换实现 = 新 EvidenceResult 绑定实现 digest；
- Q-L11-01/L11-03/L11-04/L11-08（学习率/promotion/保护/遗忘）→ 机制原样，对象从表格计数扩展到权重；
- Birch 首评前瞻风险册「表格贝叶斯 ~10⁴ 状态规模天花板」→ 处置路径明确：P4-α 兑现，届时 Birch 复评（P4-δ 挂钩）。
