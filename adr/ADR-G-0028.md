# ADR-G-0028：P3 规划——T1"LLM 作编译器"路线（owner 2026-10-11 批准分级方案）

> 状态：**ACCEPTED**（≡ CONFIRMED，owner 批准 + AI-v2 细化）· **2026-10-11**
> 前置：Birch 首评 0.75 / VIABLE_SO_FAR（Q-L13-18）→ owner 问询"是否修改限制采用现代 AI"→ 分级方案获批。

## 1. 路线裁定（owner 认可）

| 层 | 内容 | 纪律代价 | 状态 |
|---|---|---|---|
| **T1 LLM 作编译器** | 大模型在运行时之外生成/扩充**冻结工件**（语言录制语库、蒸馏查找表、动力学表）——主体运行时保持全确定 | 零（D-10 完整；LLM 是开发工具非认知部件） | **本阶段执行** |
| T2 冻结权重神经模块 | 经 promotion 门准入（确定性推理 + 消融 + 回放 + 回滚） | 证据降"可复算不透明" | 备而不发（视觉解锁时首裁） |
| T3 实时对话 LLM 在环 | 语言参与认知 | 认识论隔离拆除 | 缓（哲学评分线给出理由前不动） |

## 2. P3 序列（T1）

- **单元 A（本批）**：R-REPORT 语库建设——冻结内部状态 schema → LLM 渲染忠实自述句 → 录制回放（Q-L12-03 纪律原样）；接 ReplayStore fail-closed。
- **单元 B**：TTS 语音输出面——离线确定性 TTS（piper 中文声，双跑 digest 验证）→ WAV → AudioActuator L4 有界播放（Q-L10-17）。
- **单元 C**：**第一句话闭环真机**——内部真态 → typed 报告 → R-REPORT 回放句 → TTS → 扬声器发声 → 麦克风收到语音能量 → 证据工件。主体物理域第一句自述。
- **单元 D**：Birch 复评（B0-3 phenomenal reports PARTIAL→PRESENT 候选）+ 报告锚。
- 持续线：语库按可报告状态扩展；T2 框架裁决待触发。

## 3. 裁决批（随本 ADR）

- **Q-L12-09**：R-REPORT 语库（见登记册）——冻结状态 schema（energy/energy_trend/integrity/current_goal/valence 五字段，值域=主体可表示域）；输出合同 = 一句第一人称中文自述**只陈述给定事实**（禁编造）；录制回放纪律 = Q-L12-03 原样（miss 即 fail-closed）；**零后验权重不变**（语言仍不写信念——T3 前提未动）。
- **Q-L10-17**：语音输出面——TTS = 离线确定性（piper 固定模型，双跑 bit-exact 验证入证据）；播放经 AudioActuator L4 封套复用（≤5s/幅值界/estop 常设）；**语音 = 动作**（audio_play 的 speech 子型，effects=physical_limited）。

## 重开条件

- TTS 双跑不 bit-exact → 换确定性更强的引擎（经新 Q）；
- 语库语义越界（渲染事实超出输入 schema）→ 逐条重录 + 册版本升位；
- T2 触发（视觉解锁/状态超 10⁴）→ 新 Q 走 promotion 门。
