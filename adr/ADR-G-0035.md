## §2 探针可复算规格（REV-0013 R1 纪律——全量成文）

**任务形**：动作条件化 RSSM，input_dim = 4 = [energy_rate, move, rest, forage]；训练流 = 真实 MW0 冻结流（formed INTERO 能级差分 + 拍动作标签；master = b"p4-gamma-probe" 派生 seed_for(label)；256 cycles；脚本 = 既有混合形 rest@11/forage@{1,4}/move 其余）。训练 = P4-α 冻结超参继承（init_seed 20261011 / lr 1e-3 / Adam / 300 epochs / target rate 维）。

**载体一（EFE-MPC，Q-L08-11/Q-L10-18）**：每拍滤波真实历史（尾 64 拍）→ 8 候选 4 步计划枚举（PLANS 冻结集：RRRR/RRRF/RRFF/RFFF/FFFF/MMMM/RMRF/FRFR——R=rest/M=move/F=forage）→ 条件化想象（x 速率位 = 上拍预测——误差反馈速率位恒 0 即"无观测"语义，动作位 = 计划）→ EFE = pragmatic（想象能量对 set-point 0.7 偏差负积分）+ 0.1 × epistemic（先验 logvar 负和）→ argmax（tie → 小索引）→ 滚动执行首动作。基线 = 冻结脚本（反应式）。8 世界种子配对，每回合 64 cycles。

**载体二（做梦巩固，Q-L06-09）**：两相流（phase1/phase2 = 不同世界种子）。P1 模型（相 1 前半训练 300）→ 微调 100 epochs（Adam 1e-3）从 P1 权重起步：(a) 仅相 2 前半；(b) 相 2 前半 ⊕ dream 600 步（P1 自 imagine——速率位 = 预测、动作位 = argmax 预测——生成式重放）。遗忘 = 相 1 后半 held-out MSE 增量。

**载体三（在线门，Q-L11-09）**：双域不退化门 = 新任务 held-out ≤ 仅微调臂 ∧ 旧任务 held-out ≤ pre × 1.5。

**实测（probe_report.json，verdict=PASS）**：MPC 优势 **+0.0647（8/8 种子胜）**；forget_a **+0.000186** vs forget_b **−0.000105**（睡眠增益 **+0.000292**——重放臂不遗忘反改善）；门判别 **A 拒 / B 入**；规划双跑 **bit-exact**。

## §3 判据冻结（stat plan v1.0 → REV-0031 前置零变动）

- claim1 MPC 规划优势：配对均值差 > **0.02**（探针 0.0647 的 ~3× margin）∧ 逐种子胜率 > **0.5**（探针 8/8）；n=16 配对世界种子。
- claim2 睡眠增益：forget_a > forget_b（探针 +0.000292）∧ forget_b ≤ 0.1×|pre|（重放臂不退化）；n=8 相位对。
- claim3 在线门判别：机械确定性（20 构造案例全对——INC-08 可失败性）。
- Holm 族 3 claim；master seed = b"p4-gamma-mind"（hex 内嵌）；device = gpu_certified_cuda（Q-T02 补裁③ 延续）。
- 去功能基线（持续/随机）= 描述性语境（Q-L13-22 收窄先例——分离形门判据）。
