## 冻结前可行性探针——可复算规格（硬机制第五次执行；16/16 全绿）

**层A 构造性机制辨识**：

| 机制 | 输入构造 | 预期 = 实测 |
|---|---|---|
| replay 等权确定性 | 20 条目四分量打分 | 权重恒 {1.0}×4；budget 8 = 2 的幂；两次选择序列恒等 |
| promotion 门 | metrics 双维 + 基线 | 主指标 d=0.6∧保护过 → ACCEPTED；d=0.4 → REJECTED_NO_GAIN；任一维退化 0.55 → REJECTED_REGRESSION（**0.2−0.7 浮点差 = −0.4999… 边界如实避开——REV-0019 R4 同族浮点边界纪律**）；保护 fail → 拒无论 held-out |
| 二阶纠偏链 | 首提案 scope {r1,r2} vs 纠偏 {r3} | data_scope 可区分（纠偏闭环前提） |
| 防刷 | 同 digest 二次重提 | 首过次拒 |
| adaptive_gain 界 | profile 值 | [0.5,2.0] + reject_and_promote 语义 |
| Laplace 合并 | (0.35, 8, 4) / (0.35, 1475, 545) | (8×0.35+4)/16 = 0.425 逐位；实测计数域保持 ∈ [0,1] |

**层B 真实 MW0 流 64 cycles**（seed = b"c5-probe"；replay/巩固/promotion 原型全链）：

- 真实知觉流逐窗类型计数（实测 64 cycles：resource 545 / empty 930 格观测）；
- 巩固原型：类型级 Laplace 合并（(α·prior + positives)/(α + count)，α=8）→ 双维 metrics（反塌缩 schema 面）；**探针驱动公式修正**：初版合并式 (count·prior+positives)/(count+1) 在真实计数下产出 1.3475 出域（先验强度误置 1 且首观测覆盖先验）——修正为 α=8 伪计数式（Q-L04-10 冻结常数）后域保持 0.99/0.003（原型口径 = 类置信计数；实现期按 Q-L06-04"同类型 × 同 regime 经验计数"精化类内频率语义）；
- promotion 提案原型：metrics 向量双维 + parent_digest + content_digest；
- **双跑 bit-exact**（提案 digest 恒等 826100d1d820b06a…）+ 异 seed 发散。

**REV-0021 补注（R4/R7）**：出域值 1.3475 的代入 = 类型级 count 545【(545×0.35+545)/546 = 1.34753——初版公式将"该类全部判定数"代入 positives 且先验强度误置 1；REV-0021 评审逐位复现确认】。探针分母 16 = 层A 12 项（REV-0021 重演核对）+ 层B 4 项（B1–B4）。评审重演另确认：promotion 门退化判定 ≥ 含等号（恰 0.5 亦触）；真值恰 0.5 的退化经 float64 差构造（0.7−0.2）将逃逸 |d|<0.5 规则——实现期测试须钉死边界对（Q-L12-05 体例）。

层B 为编排规格（REV-0017 R2 口径——探针脚本按临时脚本纪律未入库）；层A 全部构造式第三方可复算。

## C5 实现期全范围声明（防范围收窄；HLD §10.4 C5 行 + L11 §9 C5 行全体）

1. **L11 promotion/rollback 全量**：LearningProposal 五类（ADAPTER/CALIBRATION/WEIGHTS/TABLE/POLICY_PARAMS）+ PromotionGate（sealed held-out 评价 + 保护 preflight + PromotionDecision）+ registry 引用切换（候选不覆盖）+ RollbackRequest 双触发 + **二阶纠偏闭环**（回退 → 修正 data_scope → 再提案可区分 → 证明可再通过——M2"有害更新可再次纠正"义务的机制兑现）+ 防刷台账。
2. **L11 replay**：ReplayPlan（等权四分量 + budget 8/T6 + RNG 流 (learning,replay,proposal_id)）+ PROTECTED 不可降级 + AffectiveValueTag 只进优先级不进目标函数（CI 断言）。
3. **L06 C5 件**：巩固协同（T6 触发 + 类型级确定性合并 + ConsolidationReceipt）+ procedural 只读接口 + tombstone run 内永久语义确认。
4. **L13 侧**：PromotionGate 治理面（DecisionDigest 分别记录先例）+ 保护集 preflight 接线（protection_suite 112 场景确定性断言）。
5. **L09/L10 接线**：adaptive_gain [0.5,2.0] 有界面 + POLICY_PARAMS 提案类型 + 界外走 promotion。
6. **权限测试**：核心权限/安全/证据不可在线修改（L11 §9 C5 行原文）——promotion 不可触及 permission matrix/containment 白名单/保护集清单本体；procedural 引用不产生权限变化（Q-L06-08③）。
7. **c5profile.py typed loader**（INC-11）+ 测试套件 + protection_suite v2.2 增补（C5 场景只增不减）。
8. **C5 统计计划**（Holm 族 claim 级显式 + 种子派生内嵌 Q-L13-12④）→ runs_c5 runner → **n≥64 sealed 首评 ≤ c5-exit 硬前置**（顺延终止条款第六次执行）：主判据 = sealed held-out 改善（promotion 生效学习增益 d≥0.5）∧ 保护集不退化（112 场景零回归）∧ 有害更新可再次纠正（二阶纠偏闭环场景）。
