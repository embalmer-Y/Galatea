## 4. P1 被动期起步（passive→active 阶梯第一级）

**裁决**（Q-L10-11②，owner 否决权保留）：P1 被动期物理源 = **主机自身真实物理遥测**（能耗/热/负载/网络——真实物理量，非模拟）；经 PhysIOBridge（env 侧新通道源）→ `ChannelBus.submit`（唯一入口）→ ReceivedSignal → L02，不绕 Sensorium（L10 §4.6 合同）。传感本身不经 L 级门（L 级门控执行输出）；L1 passive + L2 calibration 为本批授权顶。**L4 limited 及以上 = owner 逐级授权备案点**（触发条件：Tessera 设备接入 + 对应授权信封 v≥2）。

**与 MW0 仿真域的关系**：并存不替代——MW0 为虚拟域（评价对照与回归基线，确定性 bit-exact 纪律不变）；物理域为新增通道源与执行域。两域信号走同一通道合同（DeliveryFact 分离/缺失不静默补零/时间语义 effective_time≠delivered_time 全部沿用）。

**范围声明（REV-0025 R3：HLD §10.4 P1 行五元素逐项处置）**：① PhysIO Bridge = 本冻结合同（Q-L10-10③ 桥接路径）；② **BodyGraph = L4+ 执行面随设备新增事件交付**（设备/能力拓扑图以设备登记表承载；被动期 v1 只读无执行面故缺席——显式声明非静默，禁视为遗漏）；③ L0–L5 = Q-L10-11；④ 四类授权 = §3 信封实例化；⑤ passive→active = §4 阶梯（本批授权顶 L2）。

## 6. 冻结前探针（硬机制第六次执行）——实测结果（2026-10-10）

**层A 机械锚（全过）**：
- 能量派生独立复算：jiffies→busy_rate 重算与采集记录逐位一致（64 cycles mismatch=0；round 6dp）；busy 实测带 [0.000955, 0.001927]（空闲机），energy 代理 ≈ 0.998。
- L0–L2 状态机全转移表 12 断言全过：L1 拒任务（REJECTED_PASSIVE）/ L1→L2 合法授权 / L2 跑校准拒任务 / estop→L0（EmergencyStopExecuted）/ L0 拒一切且 fault 不再降（地板）/ 降级重授权只回 L1 / fault 后须 reauth / 逐级禁跳无 L1→L4 入口。

**层B 真实数据流（全过）**：
- 主机真实遥测 64 cycles × 500ms（全非特权源：coretemp 27–36°C 实测/nvme/acpitz/loadavg/procstat/meminfo/netdev）→ 流 sha256 `6c7e2712…`（主机侧与开发机侧逐字节一致）→ INTERO 合同内 payload（energy=integrity 语义对齐 Q-L01-10①；原始物理量只入桥证据侧 log——DeliveryFact 分离）→ **未改动 c0 冻结形成管线**（SensoriumPipeline，零改动零新阈值）→ 60/64 FormationReceipt（尾部 4 = W_align=4 窗未关，语义正确）→ **重放 bit-exact = True**（记录-重放范式 Q-L13-13① 机械核心实证）。
- **可读性发现**：RAPL energy_uj = 0400 root-only（实测 Permission denied）——v1 能耗 = 派生代理（与 MW0 派生差分同构），精确能耗随特权授权/设备事件再评，禁伪称直接测量（p1 profile sources.rapl_energy.disposition）。

**部署就绪（探针①）**：git archive HEAD（35.7MB）推送主机 → uv 0.13.0 安装 → `uv sync`（Python 3.12.13 钉版自动就位）。**部署发现三项（如实登记，全为供应面非代码缺陷）**：① 部署载荷 = 两部分——代码（git archive）+ evidence 数据面（gitignored 固有，tar+sha256 走备份通道；缺数据 → evidence 依赖测试 8 failed + 5 errors，定性为载荷缺失）；② 非交互 SSH 无 `~/.local/bin` PATH——测试子进程 spawn `uv` FileNotFoundError（部署脚本 PATH 义务）；③ 主机无 git——static_reports 生成器 spawn `git` 取 git_head（apt 安装 2.53.0）。**终态：主机 pytest 基线 = 695 passed（与开发机全等，2026-10-10 实测）——部署就绪判据满足**。evidence tar 首传**传输完整性校验**（整体 digest 两侧一致 `fa02b3bd…`）通过；**Q-L13-14② 恢复演练（还原临时目录 → 逐件 digest 一致）按裁决原文保留至 P1 实现期首次执行**——本单元宣称收窄为传输校验（REV-0025 R4 勘误）。开发工作区纪律不变（Windows）。

**范围发现（如实登记）**：① RAPL 特权面（↑）；② 主机无 MCU 接入——Tessera 真机流（输入真值流/摄像头）属设备新增事件，P1 被动期 v1 物理源 = 主机遥测；③ 桥接 zenoh 协议面随 Tessera 设备事件进入实现期（合同已在 Q-L10-10③ 钉死：PhysIOBridge→ChannelBus 唯一入口）。
