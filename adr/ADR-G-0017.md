## 冻结前可行性探针——可复算规格（硬机制第三次执行；结论全锚命中）

**层A 机制辨识（合成确定性输入）**：

| 机制 | 输入构造 | 预期 = 实测 |
|---|---|---|
| Pareto 支配 | z=(0.9,0.4,0.6,0.4,0.7) vs x=(0.8,0.2,0.5,0.3,0.6) | front={z}（z 逐维 ≥x 且严格）|
| 互不支配 | x vs y=(0.7,0.3,0.5,0.3,0.6) | front={x,y}（x_viab>y_viab 但 y_norm>x_norm）|
| 优先序 | front={a(OTHER,0.9), b(VIABILITY,0.1)} | 选中 b（类压倒分）|
| ω 评分 | 分量全 0.5，factor=2.0（**评分式成本项 = −ω_cost·cost**，L09 §4.2 字面——REV-0017 R3 钉死；Q-L08-03 的 (1−c) 齐向仅 Pareto 向量分量面） | factor=2.0 → (0.5+0.5−0.5+0.5+1.0)/5 = **0.4**；factor=0.5 → (0.5+0.5−0.5+0.5+0.25)/5 = **0.25**（REV-0017 R1 同表勘误：初版 0.6/0.45 系齐向误读——评审实证两读法分叉后钉死） |
| 元决策 | SEEK_HELP∧OBSERVE 同触 | SEEK_HELP（非 ACT 触发优先）；空触发表 → ACT |
| 滞回锁定 | 条件成立 0/2/5 窗 | False/True/True（≥2 连续成立窗即切换——REV-0017 R1 勘误：初版第三场景 False 系笔误，语义不可推导；False 仅在条件不成立时）|

**层B 真实流耦合（MW0+ChannelBus 64 cycles，seed = sha256(b"c3-probe-seed")，C2 同构深耗能段 60 moves + 4 rests，REQUEST+NORM typed 注入 @30）**（REV-0017 R2 宣称收窄：本节为**编排规格**——供实现期复演链路；digest 级 bit-exact 恒等需七源原型完整编排，探针脚本按临时脚本纪律未入库，digest 前缀 249b67c0… 为探针当次运行留痕）：

- 七源动机生产者最小原型全链：VIABILITY（C2 告警分级 severity_of）→ AFFECTIVE（C2 AffectPipeline motive 提案 urgency>0.1）→ MISMATCH（|Δe|>0.1 代理）→ OPPORTUNITY（窗中心 posterior ≥0.5）→ REQUEST/NORM（typed 注入）→ COMMITMENT（无 OwnedGoal 空源）→ CURIOSITY（窗 1−p 均值 >0.6）。
- C-3 冲突检测：front>1 = 冲突拍——**4 拍触发**（真实流非合成）。
- Pareto front → 优先序选择：pick 分布 = VIABILITY 48 / CURIOSITY 8 / OPPORTUNITY 3 / none 5——**AFFECTIVE 零独占**（L05 §9 C3 合同实证）；优先序压倒效应可见（VIABILITY 类高 urgency 恒胜——设计语义）。
- 元决策分布：ACT 64/64（OBSERVE 触发面 = abstain 事件，本探针无 threshold override → abstain=0 如实；SEEK_HELP/ABANDON 构造不触发——能力边界/无 OwnedGoal，如实记录）。
- **双跑 bit-exact**（pick/decision/front 轨迹 digest 恒等，digest 前缀 249b67c0…）。
- **范围发现（实现期事项）**：MISMATCH 源在慢耗能流（0.01/拍）下未触发（|Δe|>0.1 代理过粗）——实现期接 Q-L04-04 快分量二阶差分；COMMITMENT 空源 = 构造性（无 OwnedGoal）。
- 任何重演者：按上表构造式与 seed/编排定义可独立复现（层A 全部 + 层B digest）。

## C3 实现期全范围声明（防范围收窄）

C3 交付面 = HLD §10.4 C3 行 + L08 §9 + L09 §9 C3 行全体：
1. **L08**：七类动机源生产者全接线（c3_motivation.profile wired_sources——VIABILITY 告警事件/AFFECTIVE C2 提案/MISMATCH 快分量/REQUEST+OPPORTUNITY M1 语义/COMMITMENT ACTIVE 集/NORM typed/CURIOSITY 熵提案）+ C-3 冲突检测 + Pareto 仲裁（front + 优先序 + ArbitrationTrace.dropped）+ 承诺检查清单 C-3/C-4 激活；
2. **L09**：三类控制器（Habit/ModelBased/ActivePerception）+ 提案评分仲裁（ω 等权 + affect_factor 消费 C2 调制台账）+ metacontrol 五元决策状态机（触发/驻留/滞回/checkpoint）+ MonitorSignal（loss_of_control 面可计算）+ `affect/drive 不直达执行` 权限测试；
3. **统计计划**（实现期）：动机选择可复算判据 + AFFECTIVE 不独占 + metacontrol 切换可检出——Holm 族显式声明 + 种子派生入计划 → n≥64 sealed 评价（顺延终止条款）→ REV-0018 → c3-exit。

## C3 退出判据与控制器启用电的衔接（REV-0017 R5 闭环）
