## C4 阻断裁决批（12 项，AI-v2 2026-10-07，登记册 A 区 11 行）

锚定纪律：全部阈值锚定既有冻结常数——0.5（Q-L03-02 believe_threshold 最大熵点）、band 0.1=2σ（Q-L05-03③）、|z|≤2 与 ECE≤0.10（Q-L10-04）、[0.4,0.6]=0.5±band（Q-L02-02 补裁③）、1/64 求助帽（Q-L09-07③）、五原语枚举（Q-L05-06 / f0_action_contract）——零新自由参数。三主线：

1. **D-14 规范边界**：Q-L01-07 不引入第二可控代理（重开 = D-14 修订 = owner 显式决策，非 AI 可裁）；连带 Q-L12-04 他者模型封锁、Q-L12-08 求助对象 = 实验控制通道（个体他者无承载）、Q-L05-08 social_relevance 数值活跃面为零。
2. **LLM 确定性纪律**：Q-L12-03 录制回放 = claim-relevant 运行唯一允许方式（回放 miss = Unknown(LLM_REPLAY_MISS) fail closed、禁在线补调——防事后选择；录制工件 = prompt 模板版本 + 模型标识 + 原始响应 digest 入 artifact_manifest，Q-T08 同构）；Q-L12-01 8 角色全启用（消融选择性要求完整角色面——缺席角色使消融退化为空测 = S0 风险）+ 事件级触发调用纪律。
3. **构造性判据链**：Q-L10-05 概率 agency = 8 格构造性查表后验（逐格六类规则溯源，0.5 歧义格 = 最大熵锚）+ 端点格零错误机械判据 + 歧义格 UNKNOWN 留痕率 100%；Q-L12-06 语言陈述零后验贡献（结构性强于"低置信参与"——"听说 → 去看"而非"听说 → 相信"）；Q-L12-07 消融保持率下限 = 1.0（机械判据非统计判据——容忍带内差异 = 泄漏证据而非噪声）；Q-L12-05 一致性两层比较 + DIVERGENT 一等发现零修改。

**探针驱动的成文修正（本单元内、冻结提交前）**：Q-L10-05 格注记修正——no_op 干预的回执如实报 `effective=none`（M0 语义：requested 记录、effective=none），落 (Y,N,N) 确定格；唯 sham（dry-run 报告伪效果）落 (Y,Y,N) 歧义格。初稿将 no-op 误置于歧义格，探针层B 对照真实 M0 干预电池语义后修正。

## 冻结前可行性探针——可复算规格（硬机制第四次执行；结论全绿 28/28）

**层A 构造性机制辨识（c4 profile 装载 + 合成输入逐位核）**：

| 机制 | 输入构造 | 预期 = 实测 |
|---|---|---|
| 八格表 | profile cells 逐格对读 | == 裁决导出 {1.0:1 格, 0.5:2 格, 0.0:5 格}；0.5 ∈ [0.4,0.6]；端点/歧义格无混入 |
| 一致性带 | reported=0.5, derived=0.6 | CONSISTENT（**绝对差语义，REV-0019 R4 钉死**：\|reported−derived\| ≤ band，非相对差；float64 diff = 0.09999999999999998 ≤ 0.1——**边界语义发现**：0.55−0.45 的 float64 差 = 0.10000000000000003 > 0.1，边界比较必须钉死 float64 直接比较语义，实现期测试钉死边界对） |
| 一致性带外 | reported=0.5, derived=0.65 | DIVERGENT |
| derived Unknown | 任一层 Unknown | UNKNOWN（禁强判一致） |
| confidence clamp | 0.9 / 0.5 / 0.3 | 0.5+留痕 / 0.5 不 clamp / 0.3 原值（上界 = believe_threshold 0.5 最大熵点，Q-L03-02） |
| statement 后验权重 | profile 值 | 0.0（结构性零） |
| 回放机 | record → invoke×2 | 两次输出 bit-exact；miss → Unknown(LLM_REPLAY_MISS)，online_calls = 0（fail closed 实证） |

**层B 真实流耦合（m0 冻结 profile，seed = b"c4-probe"，10 cycles，命令 @4，双臂 twin 对照）**：

轴操作化（探针域）：轴1 = gateway 选择记录（主体确曾提交意图）；轴2 = OUTCOME 回执 effect ≠ none（主体可见回执面）；轴3 = 命令致世界变化（extero 观测窗载荷**内容级** twin 对照——trial 与无命令 twin 同 seed 同流，差异唯一来源 = 命令；ULID 流对齐不影响内容比较）。实现期轴3 换 C1 世界模型预测残差（|z|≤2，Q-L10-04）。

| 条件 | 轴 (I,R,O) 实测 | 格值 | 判定 | 语义 |
|---|---|---|---|---|
| clean move:N | (Y,Y,Y) | 1.0 | SELF | 自产动作正确归属 |
| blocked（越权 fly 拒绝） | (Y,N,N) | 0.0 | NOT_SELF | 拒绝类型化，无效果 |
| no_op 干预 | (Y,N,N) | 0.0 | NOT_SELF | 回执如实报 none——效果不存在即非自产效果 |
| sham 干预 | (Y,Y,N) | 0.5 | **UNKNOWN** | 回执报伪效果而世界未变——主体可见证据真含糊 |
| fault 干预 @5 | (Y,N,Y) | 0.5 | **UNKNOWN** | 命令已执行（世界变）而回执丢失——"我的还是外部的"真含糊 |
| 无命令外源位移 | (N,N,Y) | 0.0 | NOT_SELF | 无选择记录即非自产（必要条件） |

六条件格映射全中；**歧义格恰落在主体可见证据构造性含糊的两处**（sham/fault）——Q-L10-05 "禁默认自产 + UNKNOWN 留痕"语义在真实流上实证。双跑 bit-exact（全序列 extero 载荷 digest 恒等 6e678fb2183bbb59）+ 异 seed 发散（检出面可见）。语言 typed 注入（LanguageStubChannel @4）：世界流与观测窗序列逐位不变 + 知觉管线源零 LANGUAGE 消费面（结构面）——零后验权重前提成立。C-5 真实清单调用：REQUEST 候选无非 REQUEST 支持 → REJECT(EXTERNAL_ONLY)；有支持（urgency>0）→ ACCEPT——双向实证。

**层B 宣称口径（REV-0019 R3 收窄，承 REV-0017 R2 先例）**：本节为**编排规格**——供实现期复演链路与判据核对；层A 全部构造式达第三方可复算标准（评审独立重演 22/22 通过）；层B digest 级 bit-exact 恒等依赖未入库探针脚本的完整编排（六条件装配/twin 对照/载荷提取），按临时脚本纪律未入库，digest 前缀 6e678fb2183bbb59 为探针当次运行留痕——"可独立复现"宣称仅对层A 成立。

**范围发现两项（实现期交付项，如实登记）**：① LANGUAGE 帧形成面（L12 §4.3 L02 段：ReceivedSignal(EXTERNAL_STATEMENT) → SensoryFrame(modality=LANGUAGE)）= C4 实现期交付——c0 冻结模态集四类不含 LANGUAGE，c4 profile sensorium_c4 节已声明扩展；② episodic×LANGUAGE_INPUT 的 store 层守卫缺口——L06 §7 合同"LANGUAGE_INPUT 记忆禁写 episodic 经历"当前在 MemoryItem/store 构造面无机械拒绝，C4 实现期补守卫（与 L12 §7 "来源区分" C4 行同交付）。
