# ADR-G-0001：F0 阻断清零批次（19 项裁决）选项空间补档

> 关联：`design/open_questions.md` A 区 2026-09-23 批次 · `_audit/reviews/REV-0001.md`（R1 闭环）· DEV_SPEC §4.5（Q 记待裁决什么，ADR 记为什么这样裁）
> 动因：REV-0001 发现该批 19 项裁决均未落盘"被否选项"（选项空间对比 0/19），未来会话无法回答"为什么不是另一种方案"。本 ADR 一次性补档。
> 附带决定：ADR 目录位置 = 仓库根 `adr/`（ACT-05 闭环；DEV_SPEC 附录 D Q-DEV-01 的位置子项随之定）。

## 逐项选项空间（主要被否项与理由）

| Q 号 | 已选 | 主要被否选项 | 否决理由 |
|---|---|---|---|
| Q-L01-06 | 重建映射采纳为规范 | 继续等原文；弃用旧映射仅从门判据重推导 | 原文不可得且无人可提供 = 永久阻塞；旧切片承接关系是仅存谱系，弃之损失溯源 |
| Q-G00-06 | 最小集 + 其余 RESERVED | 臆测补全；永久放弃未重建符号 | 臆测 = 伪造不可证伪的历史合同（违 D-10 与认识纪律）；放弃 = 零收益舍弃命名空间（D-1…D-9 空号保留先例，DEV_SPEC §13） |
| Q-G00-04 / Q-L13-04 | card_04 原文枚举 | 自行增删类/型 | 有出处文本在档（archive/card_04.md:43），任何"优化"都是无据重建 |
| Q-L10-01 | 硬配额两级制 | 不设配额（M0 后再定）；仅软预算 | 无配额则 `BUDGET_EXCEEDED` 路径 MW0 不可测，归属/元控制实验缺一条可干预路径 |
| Q-L10-03 | 六级（L0 为不可授权地板） | 五级连续谱（card_06 原表述）；L0 亦作可授权档 | 硬保护必须是不可谈判的地板；五级谱把地板与授权档混列，fail-safe 语义被稀释 |
| Q-L10-06 | 四类统一信封 12 字段 | 四类各自独立 schema | 生命周期字段高度同构，分立 schema 徒增漂移面与校验面 |
| Q-L11-07 | 向量 schema + 四项最小标准集 | 各档自定义指标 | L13 跨候选比较需同名同义；自定义破坏可比性 |
| Q-L12-02 | 写端口角色×内容类型双维 | 仅角色级 | 角色级下"模板受限输出"不可机械校验（R-TRANSLATE 反例） |
| Q-L13-01 | Holm–Bonferroni 默认 | 朴素 Bonferroni；BH 作默认；不设默认 | 朴素过保守；BH 控 FDR 不控 FWER；无默认 = 每计划重议引入自由度 |
| Q-L13-02 | 70/30 + digest 交集判据 | 50/50；按时间轮换分割；人工清单分割 | 50/50 牺牲 internal 数据量；时间轮换引入分布漂移；人工清单不可复算 |
| Q-L13-09 | 统一册 + 分领域初值 | 全局单一阈值；各 Q 各自为政 | 单一阈值忽略判据性质差异（初值已分：d / ECE / R² 三型）；各自为政破坏同标度比较 |
| （联动 7 项） | 随 Q-L13-09 成组初值 | 逐项独立到各门再定 | 同源标度问题分散裁决会造成跨 claim 不可比；初值已各自标明门时复核点 |
