## §2 探针规格（全量成文，评审可独立重演——REV-0013 R1 纪律）

**层A（torch 机器面，4 检）**：① 配置生效：`torch.use_deterministic_algorithms(True)` + `set_num_threads(1)` + float32 默认；② 种子敏感性：同种子初始化 state_dict 逐键 sha256 恒等、异种子（seed+1）必须不同（否则断言空转）；③ 冻结权重双跑 bit-exact：同输入两次前向 `numpy().tobytes()` 恒等；④ 权重篡改检出：单权重 +1e-3 → digest 变化。

**层B（真实数据流面）**：
- **流**：MW0World + MW0Dynamics + ChannelBus + 三通道 + SensoriumPipeline（真实冻结 m0/c0 profile，生产链路非替身）；master seed = `b"p4-alpha-probe"`（Q-L13-12 同族任意先钉）；256 cycles；**动作脚本 = 评估侧驱动**（C1 判据 3 同族外源面——主体面零命令信号）：周期 12 = [move, forage, move, move, forage, move×6, rest]，恒向 E；主体数据 = 仅 RECEIVED 渲染窗/内感受形成帧（窗值有界断言 = P14 语义）；
- **数据集**：速率递归——输入 = 12 滞后内感受能量变化率（形成面派生差分 Q-L02-05⑤，差分平稳化），目标 = 下一速率；末 64 对 = held-out（T6 拍），其余 = 训练；
- **模型**：线性 12→1，种子化 Generator 初始化（0.01σ，禁全局 RNG）；**全批量 Adam lr=0.01 × 600 epochs**（无 minibatch 采样 RNG——训练确定性由构造成立）；
- **学习会话录制/重放（Q-L13-20①）**：录制 = {master seed, init seed, 流 digest, 权重前后 digest, 损失首/末, lr, epochs}；重放 = 同种子同数据 → 末权重 digest 逐位恒等 + 损失曲线末位恒等；
- **判据（全部可失败）**：训练损失必须下降；held-out 模型 MSE **< 持续基线 × 0.1**（实测比 0.0083——12× 余量）；冻结推理双跑 bit-exact；消融偏移 mean|pred−persist| > 1e-4（模型输出与持续基线可检出地不同）。

**实测结果**：流 digest `7d8aa887…4b61`（250 窗）；损失 0.000825 → 0.000113；held-out 模型 MSE **6.89e-6** vs 持续基线 8.34e-4（**比 0.0083**）；双跑/重放/篡改检出/种子敏感性全过。**verdict = PASS**。

**探针驱动的设计修正（如实留痕——初版两次失败教训）**：① 初版 next-window 窗预测任务在 held-out 段退化为恒零（资源稀疏场，主体 wandering 至空区，持续基线 MSE=0 不可击败）——任务改内感受速率递归；② 电平输入在漂移序列上外推失败（train/held 分布移位，比 3.69）——差分平稳化修复；③ 方向轮转脚本使映射为四方向混合——恒向脚本 + 速率窗承载位置信息。**教训：探针任务必须先证持续基线可击败（非平凡基线）**，INC-08 同族。

## §3 裁决摘要（全文见登记册 A 区）

- **Q-L04-12**：P4-α 范围 = RSSM 式潜状态世界模型 + 摊销推断（10⁴–10⁶ 参数 CPU 级）；训练双域（MW0 冻结流 + p1 sealed 语料）；表格模型并存为回退层/对照基线；判据 = held-out 配对 sealed 评价；转移语义继承 Q-L04-09（禁信念内模拟隐藏真值）。重开：超实时预算降尺度 / 无增益如实 INCONCLUSIVE。
- **Q-L13-20**：训练会话录制格式 v1（seed×2 + 数据 digest + 权重前后 digest + 损失曲线 + 超参）；重放判据 = 末权重逐位恒等；权重 = registry 内容寻址工件 + manifest 锚；NeuralModule 接口（Q-T02①）= state_dict + digest + parent_digest；部署双跑 bit-exact = 晋升机械判据；minibatch 采样必须经 L00 RNG 流。
- **Q-G00-15**：P4-α 初值集伞式——确定性配置（torch 2.14.1+cpu / 单线程 / deterministic / float32）+ 探针锚（流 digest / held-out 比 0.0083 / 判据阈 0.1）入 p4_alpha_brain.profile v1.0。
